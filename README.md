# CodeVault – Developer Snippet Manager

A centralized workspace for storing, organizing, and managing reusable code snippets.

## Project Status

**In Development**

CodeVault is an ongoing full-stack development project. The application is being built to provide developers with a simple and efficient way to store, organize, search, and reuse code snippets.

Features and functionality are being implemented progressively.

## Overview

CodeVault is a developer-focused application designed to simplify code snippet management.

It provides a centralized space where developers can save frequently used code, organize snippets by programming language, assign custom tags, and quickly retrieve code whenever needed.

The project aims to improve developer productivity by making reusable code easier to manage and access.

## Planned Features

- User registration and authentication
- Create, view, update, and delete code snippets
- Organize snippets by programming language
- Create and manage custom tags
- Mark snippets as favourites
- Search and filter snippets
- Copy code snippets directly
- Personalized dashboard for managing saved snippets
